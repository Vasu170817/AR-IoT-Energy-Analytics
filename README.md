#Augmented Reality IoT Control System with Real-Time Energy Analytics

## Project Overview
An IoT-based system that enables real-time electrical appliance control and eneergy monitoring through an Augmented Reality interface

## Technologies Used
- Python
- IoT
- ESP8266
- MQTT
- Augmented Reality
- Data Analytics
- HTML/CSS

## Hardware
- ESP8266
- Relay Module
- Voltage Sensor
- Current Sensor

## Features
- Remote appliance control
- Real-Time energy monitoring
- AR-based control interface
- MQTT-based communication
- Energy usage analysis
